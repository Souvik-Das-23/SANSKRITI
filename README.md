## 📖 Overview

**Sanskriti** turns fragmented Indian civilizational heritage — scattered across ancient scriptures, ruined rock-cut temples, living classical dances, and rural artisan traditions — into an immersive, sovereign digital experience. It bridges 5,000 years of cultural wealth with sovereign Indian technologies: **Bhashini Indic Voice AI (MeitY)**, **Google Gemini 1.5 Flash Multimodal Vision**, **PostGIS Geospatial Proximity Audio**, **ONDC Fair-Trade Guilds**, **Polygon PoS Soulbound Provenance**, and an **Offline-First SMS Pilgrim Safety Beacon**.

> **Note on Prototype Status**: This is a fully functional, test-verified prototype developed by **Team CultureX**. Every feature and service described in this document corresponds to real, executable code in this repository — nothing here is aspirational.

---

## 🎯 Problem Being Solved

1. **Fragmented & Commercialized Cultural Data**: Historical chronicles, dynastic lineages, and architectural treatises (*Nagara, Dravida, Vesara*) are scattered across unverified blogs with zero authentic Indian Knowledge Systems (IKS) backing.
2. **Neglect of Intangible Cultural Heritage (ICH)**: Living traditions (8 classical dance forms, mudras, ancient martial disciplines, subterranean stepwell hydro-engineering, and acoustic Vedic chanting) lack interactive digital preservation.
3. **Exploitation of Rural Master Artisans**: Middlemen siphon up to **70% of artisan revenues**, while tourists are scammed with counterfeit machine-made replicas of Geographical Indication (GI) tagged crafts.
4. **Disconnection of Youth & Global Travelers**: Static museum placards and text boards fail to engage Gen-Z travelers without 3D models or Augmented Reality time-travel reconstruction.
5. **Zero-Connectivity Safety Hazards in Remote Sites**: High-risk remote rock-cut caves, ghats, and high-altitude pilgrimage corridors suffer complete cellular blackouts during emergencies.

---

## ✨ What SANSKRITI Does

* **Renders 360° 3D Monument Models & Kaalchakra AR Time-Travel**: Enables travelers to rotate decimated `<5MB` GLB 3D temple blueprints and swipe an interactive temporal slider to watch ruined monuments restore to their 12th-century golden era via dual-mesh AR shaders.
* **Scans Artifacts with AI Heritage Lens**: Uses Google Gemini 1.5 Flash to identify temple friezes, sculptures, and dance mudras with structured JSON outputs in `<800ms`.
* **Speaks in 12+ Indic Languages**: Integrates Government of India's **Bhashini NLTM API** for native speech-to-text, translation, and audio voice synthesis across regional dialects.
* **Preserves Intangible Traditions (Parampara Vault)**: Vaults 8 classical dance forms, mudra breakdowns, martial arts, and high-resonance acoustic Vedic shlokas.
* **Empowers Artisans via ONDC & Polygon PoS**: Connects travelers directly to verified rural artisan cooperatives (Kala Bazaar) with 0% middleman extortion and tamper-proof blockchain GI provenance certificates.
* **Protects Pilgrims Off-Grid**: Grabs hardware GPS coordinates and dispatches background SMS emergency telemetry directly to **112** (National Emergency) and **1363** (Incredible India Tourist Helpline) with zero internet.

### 🏛️ 1. 3D Spatial Heritage & Kaalchakra AR
* Interactive 3D wireframe and textured rendering of iconic monuments (Konark Sun Temple, Kailash Temple Ellora, Hampi Stone Chariot) using `model_viewer_plus` with optimized `<5MB` GLB assets.
* **Kaalchakra Dual-Mesh Temporal Shader**: A split-slider interface allowing travelers to slide between the present archaeological ruin and the reconstructed 12th-century golden era in real-time AR.

### 🗣️ 2. Sovereign Indic Voice AI (Bhashini NLTM Bridge)
* Fully integrated with the Ministry of Electronics and Information Technology's (MeitY) **Bhashini ULCA API**.
* Provides real-time Automatic Speech Recognition (ASR), Neural Machine Translation (NMT), and Text-to-Speech (TTS) across 12+ official Indian languages (Hindi, Bengali, Tamil, Telugu, Marathi, Gujarati, Kannada, Odia, Malayalam, Punjabi, Assamese, English).

### 👁️ 3. AI Heritage Lens (Gemini 1.5 Flash Multimodal Vision)
* Point-and-shoot camera analysis powered by Google Gemini 1.5 Flash with strict `application/json` schema enforcement.
* Instantly extracts:
  * Identified artifact and associated dynasty/century.
  * Architectural school (*Nagara, Dravida, Vesara, Kalinga, Hoysala*).
  * Iconographic symbolism and Mudra interpretation.
  * Archaeological Survey of India (ASI) conservation status.

### 🎭 4. Sanskriti Parampara (Intangible Cultural Heritage Vault)
* Dedicated digital vault preserving living traditions:
  * **8 Classical Indian Dances**: Bharatanatyam, Kathak, Kathakali, Odissi, Kuchipudi, Manipuri, Mohiniyattam, Sattriya.
  * **Sanskrit Mudra Breakdown**: Structural taxonomy and symbolic spiritual meanings.
  * **Acoustic Vedic Chants**: High-resonance audio player with Sanskrit shlokas, meter analysis, and English philosophical translations.
  * **Ancient Engineering**: Stepwell hydro-geology (*Baolis*) and rustless iron metallurgy (*Gupta Iron Pillar*).

### 🛍️ 5. Kala Bazaar (ONDC Fair-Trade Artisan Guilds)
* Decentralized commerce layer built on the **ONDC Beckn Protocol**.
* Connects travelers directly to verified state handloom cooperatives and master artisan clusters (Krishnanagar Clay Dolls, Varanasi Brocade Silk, Thanjavur Gold Foil Paintings, Bastar Dhokra Art) eliminating up to 70% middleman extortion.

### 🎖️ 6. Sanskriti Yatra (Polygon PoS Cultural Passport)
* Gamified national pilgrimage & heritage explorer passport spanning India's 6 cultural zones.
* Travelers earn verifiable, non-transferable **ERC-5192 Soulbound Tokens** and **ERC-1155 GI Provenance Seals** on the Polygon (PoS) blockchain for each visited site and authentic artisan purchase.

### 🚨 7. Off-Grid Pilgrim SOS Radar
* Designed for remote rock-cut caves, high-altitude shrines, and cellular dead zones.
* When triggered, `OfflineSosService` grabs hardware GPS coordinates from device sensors and formats a standardized emergency SMS dispatching directly to **112 (ERSS)** and **1363 (Tourist Helpline)** without requiring cellular data.

## 🤖 Sovereign AI Layer & Boundaries

AI in Sanskriti is strictly bounded to scholar analysis and linguistic accessibility.

### What Gemini 1.5 Flash & Bhashini Do:
* **Multimodal Artifact Recognition**: Structure raw camera frames into verified architectural taxonomies.
* **Indic Voice Translation**: Translate and vocalize monument chronicles into the traveler's native tongue.
* **Conversational IKS Guidance**: Answer historical and theological queries grounded in ASI monographs and NCERT IKS corpora.

### What AI Can NEVER Do:
* ❌ **Fabricate Unverified History**: AI prompts are locked with strict negative constraints preventing hallucinated dates or invented dynastic claims.
* ❌ **Alter Official Ticket Bookings**: ASI E-passes are cryptographically signed and stored in local/remote databases; AI cannot create or modify tickets.
* ❌ **Bypass ONDC Verification**: Kala Bazaar orders execute strictly through validated merchant endpoints; AI never arbitrates financial transactions.
* ❌ **Trigger False Distress Calls**: The Offline SOS beacon is explicitly user-confirmed and relies on deterministic hardware GPS + telephony APIs.

## ⚙️ Installation & Setup

### 📥 1. Prerequisites
* **Flutter SDK**: `>= 3.44.0` (Dart `>= 3.0.0`)
* **Android Studio / VS Code** with Flutter extensions installed
* **Connected Android Device or Emulator** (API 26+)

### 🔧 2. Setup & Installation
```bash
# Clone the repository
git clone https://github.com/Souvik-Das-23/SANSKRITI.git

# Navigate to the project directory
cd SANSKRITI/sanskriti

# Fetch Flutter dependencies
flutter pub get
```

### 🧪 3. Running Automated Tests & Code Analysis
```bash
# Verify static code health (Expected: 0 errors, 0 warnings)
flutter analyze

# Run all 16 automated unit and widget test suites
flutter test
```
*Current Baseline: **16/16 Test Suites Passed (100%)** • **0 Lint Errors**.*

### ▶️ 4. Running the Application
```bash
# Run on connected physical phone or emulator
flutter run -d android

# Run on Windows desktop
flutter run -d windows

# Run on Chrome browser
flutter run -d chrome
```

## ⚠️ Honest Limitations

* **Hackathon-Stage Prototype**: This application is a fully functional Smart India Hackathon grand-finale prototype and is currently at **Technology Readiness Level 7 (TRL-7)**.
